# Esprezzo Mobile App

A Flutter mobile application for Android and iOS to scan supermarket product barcodes, search products, compare prices across stores, manage shopping lists, and display related products. Includes user authentication (with optional login), product/category navigation, and integration with a backend API for MySQL database access.

## Features
- Barcode scanning
- Product search (by name, brand, or barcode)
- Price comparison across stores
- Shopping list management
- Related product suggestions
- Category navigation
- User authentication (optional login)

## Getting Started
1. Install Flutter: https://docs.flutter.dev/get-started/install
2. Run `flutter pub get` to fetch dependencies
3. Run the app:
	- Android: `flutter run`
	- iOS: `flutter run`

## Project Structure
- `lib/` - Main application code
- `android/` - Android-specific files
- `ios/` - iOS-specific files
- `.github/` - Copilot and workflow instructions

## Notes
- Ensure you have a compatible Java version for Android builds (Java 17 <= version < 24).
- Backend API integration and database access will be implemented in future steps.
